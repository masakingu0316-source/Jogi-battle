# 定規バトル（オンライン版）

机の上で定規をはじき合う遊びを、離れた端末どうしで対戦できるようにしたWebアプリです。
部屋を作ると5文字の部屋コードと招待リンクが出て、友だちはそれを開くだけで入れます。
Googleでログインして遊びます。戦績や集めた定規・アイテムはアカウントに保存されます。

## できること

**遊ぶ流れ**
1. Googleでログインする（招待リンクから来た人は、ログイン後にそのまま部屋へ）
2. ホームで、遊び方（モード）を選んで部屋を作る／友だちの部屋コードで入る／使う定規を編集する
3. 部屋で全員が「準備OK」を押すと対戦が始まる。人数がそろってから（最後の人が入ってから）1分たつと、準備中の人も一緒に始まる
4. 決着したら同じ部屋に戻り、また全員の準備OK（または1分）で次の対戦。抜けたい人は「部屋を出てホームへ」

**対戦**
- モード：クイック（1対1・机1台）／標準（1対1・机2台）／乱戦（3〜4人・机4台）／チーム戦（2対2・机4台）。部屋を作るときに決め、定員を超えては入れない
- 最初の1周は、落ちても元の席に戻る
- 机が消える：3人以上で始めた対戦で残りが2人になると、1周（2人が1回ずつはじく）ごとに机が1台ずつ消える（最後は1台まで）。消える机はその周のはじめから赤い斜線で予告し、消えたときに上にいた定規は落ちる（だれの手柄にもならない）。どの机が消えるかはランダムだが、残りの机が角だけでつながる形にはしない
- 必殺技：はじく（+20）・相手に当てる（1本につき+10）・当てられる（+30）でゲージがたまり、満タンなら自分の番に「必殺技を使う」を押してからはじく。技は定規の形で決まる
  - 30cm定規「剛腕」：その1打のはじく力が大きく上がる（すべる距離はおよそ2.2倍）
  - 15cm定規「連打」：止まったあと、もう1回続けてはじける
  - 三角定規（45°）・分度器「突風」：止まった場所から風を起こし、近くの定規を吹き飛ばす（分度器は範囲が広い）
  - 三角定規（30°・60°）「不動」：次の自分の番まで重さが3倍になり、押されにくい
- クリティカルヒット：はじくたびに10%の確率で発生し、最初に当てた相手へ伝わる力が1.6倍になる（すべる距離はおよそ2.5倍）。相手に当たらなければ何も起きない
- 再戦は先手が交代する。対戦中に抜けた人の席は、決着したときに空く
- 通信が切れても、開き直せば同じ席に戻れる。切れた人の番は、いちばん先に部屋にいた人が飛ばせる

**コンピュータと練習**
- ホームの「コンピュータと練習」から、上で選んだ遊び方でコンピュータと対戦できる。強さは「やさしい／ふつう／つよい」、乱戦はコンピュータの人数（2人か3人）も選べる。チーム戦は味方1人・相手2人
- コンピュータは、実際にいくつものはじき方を計算してみて良いものを選ぶ。強いほど試す数が多く、手元のぶれが小さい（定規もやさしいLv.1・ふつうLv.3・つよいLv.6）
- 練習はブラウザの中だけで動き、サーバーとは通信しない。えんぴつ・経験値・戦績は増えない

**アカウント**
- 戦績：対戦数・勝ち・勝率・落とした数・自滅、モード別の成績、最近20戦の履歴
- 定規の形：30cm定規・15cm定規・三角定規（45°）・三角定規（30°・60°）・分度器。30cm定規（3つの素材）は全員が持っていて、ほかはガチャで出る
- 定規の属性（素材）：アクリル（よくすべり、よく跳ね返る）／メタル（重くて押されにくい）／ラバー（すぐ止まり、跳ね返らない）。三すくみで、メタル→アクリル→ラバー→メタルの順に、当てたとき相手を少し強く弾ける
- 定規のレベル：対戦で使った定規に経験値が入る（参加10点、勝ち+10点、1本落とすごとに+5点）。Lv.10まで。1つ上がるごとに重さとはじく力が0.4%上がり（Lv.10で+3.6%）、Lv.3からオーラ、Lv.6から光の粒、Lv.10で金色の輪をまとう
- 定規ケース：持っている定規を選び、柄・シール（見た目）とアクセサリ（性能）を付ける。まだ持っていない定規も並ぶ
- アクセサリ：重さ・すべりにくさ・はじく力のどれかを最大5%変える。1本の定規に1つまで（レベルの分と合わせて最大10%）
- ガチャ：通貨は「えんぴつ」。確率は画面に表示。お金で買う仕組みはありません
- えんぴつのもらい方：はじめてのログイン、毎日のログイン、対戦の参加と勝ち（本数は設定画面で変えられる）

## しくみ

```
ブラウザ（public/）  ──WebSocket──  Cloudflare Worker（src/worker.js）
                                      ├ 部屋ごとの Durable Object（src/room.js）
                                      │   └ 部屋の進行と物理計算（public/shared/core.js）
                                      ├ Googleログイン（src/auth.js）
                                      └ アカウントのAPI（src/api.js）── D1 データベース（src/db.js）
```

- **サーバーが判定する**：はじいた向き・強さだけをサーバーに送り、サーバーが物理計算をして、定規の動きを全員に配ります。持っていない定規やアクセサリは、サーバーが確認して使えないようにしています。
- **ログイン**：Googleの認可コード方式（PKCE付き）。端末には推測できないセッションIDだけをクッキーで持たせ、データベースにはそのハッシュを保存します。保存するのはGoogleのアカウント識別子と表示名だけで、メールアドレスは受け取りません。
- **データベース**：テーブルは最初に使ったときに自動で作られます。
- **部屋の片付け**：6時間だれも使わなかった部屋は自動で削除されます。
- **版の確認**：`public/shared/version.js` の値をサーバーと画面で比べ、画面を開いたままの端末が古い版のときは「再読み込み」を出します（対戦中でも同じ席に戻れます）。更新を公開するときは、この値を変えてください。

## 公開のしかた（GitHub → Cloudflare）

必要なもの：GitHub のアカウント、Cloudflare のアカウント（無料プランで動きます）。
Cloudflare や Google の画面の表記は変わることがあるので、近い名前のボタンを探してください。

1. **GitHub にリポジトリを作り**、このフォルダの中身を入れる（`node_modules` は不要）
2. **Cloudflare の「Workers & Pages」→「作成」→ GitHub のリポジトリを読み込む**で、1 のリポジトリを選ぶ
3. デプロイコマンドは `npx wrangler deploy`（初期値のまま）、ビルドコマンドは空欄でよい
4. 以降は GitHub の main ブランチに変更を入れるたびに、自動で公開し直される

この時点ではログインが使えないので、ログイン画面に「準備ができていません」と表示されます。続けて「ログイン機能を有効にする」を済ませてください。

## ログイン機能を有効にする

### A. データベースを作る（Cloudflare）

1. ダッシュボードの「ストレージとデータベース」→「D1 SQL データベース」→「作成」
2. 名前を `jogi-battle-db` にして作成し、表示される **データベースID** を控える
3. `wrangler.jsonc` の `"d1_databases"` の行の先頭の `//` を外し、`ここにデータベースのID` を書き換える

### B. Googleログインの準備（Google Cloud）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る（名前は自由）
2. 「Google Auth Platform」（または「APIとサービス」→「OAuth同意画面」）を開き、アプリ名（例：定規バトル）とサポート用のメールを入れる。対象は「外部」
3. 「クライアント」→「クライアントを作成」→ 種類は「ウェブ アプリケーション」
4. 「承認済みのリダイレクト URI」に次を追加する（自分のURLに合わせる）
   `https://jogi-battle.<あなたのサブドメイン>.workers.dev/auth/callback`
5. 作成後に出る **クライアントID** と **クライアントシークレット** を控える
6. 「対象」（Audience）で公開ステータスを「本番環境」にする。テスト中のままだと、テストユーザーに登録した人しかログインできない
   （このアプリが求めるのは名前などの基本情報だけなので、Googleの審査は通常いりません）

### C. 値を設定する

1. Cloudflare のダッシュボードで、この Worker の「設定」→「変数とシークレット」→「追加」から、種類「シークレット」で次の2つを登録する
   - 名前 `GOOGLE_CLIENT_ID`、値にクライアントID
   - 名前 `GOOGLE_CLIENT_SECRET`、値にクライアントシークレット
2. `wrangler.jsonc` の変更（データベースID）を GitHub に入れる（自動で公開し直される）

クライアントIDもシークレットも、GitHub のファイルには書かないでください（GitHub の検査で警告が出ます）。

画面右上に「Googleでログイン」が出れば完了です。

## 設定画面（管理者だけ）

`https://jogi-battle.<あなたのサブドメイン>.workers.dev/admin.html` で、コードを触らずに次のことができます。

- えんぴつ：ガチャの値段、はじめてのログイン・毎日のログイン・対戦でもらえる本数、対戦の1日の上限
- 定規の経験値：対戦に使った・勝った・1本落としたときの点数
- ガチャ：レア度ごとの確率（重み）と、かぶったときに戻る本数
- アイテム：ガチャに出すかどうか、アクセサリの効き目（−5〜5%）
- ユーザー：表示名やアカウントIDで探して、えんぴつを配る・減らす

保存した値はデータベースに入り、30秒ほどで全体に反映されます。「初期値に戻す」で、コードに書いた値（`public/shared/catalog.js`）に戻ります。

**管理者の登録**
1. 自分のアカウントでログインし、マイページの「戦績」タブの下にある **アカウントID** を控える（設定画面を開いたときにも表示されます）
2. Cloudflare でこの Worker の「設定」→「変数とシークレット」→「追加」から、種類「シークレット」、名前 `ADMIN_USER_IDS`、値にアカウントIDを登録する（複数人ならカンマ区切り）
3. 1〜2分後に設定画面を開き直す

## 手元で動かす（任意）

Node.js 18 以上が必要です。

```sh
npm install
npm run dev     # http://localhost:8787 で起動
npm test        # ルール・部屋の進行・データベースのテスト（データベースのテストは Node 22.5 以上）
```

手元でログインを試すときは、Google 側のリダイレクト URI に `http://localhost:8787/auth/callback` も追加し、
`.dev.vars` というファイルに `GOOGLE_CLIENT_ID=...` と `GOOGLE_CLIENT_SECRET=...` を書いておきます（このファイルは GitHub に入りません）。

## ファイル

| ファイル | 内容 |
|---|---|
| `src/worker.js` | 入口。部屋の作成・接続、ログイン、API、画面の配信の振り分け |
| `src/room.js` | 1部屋＝1つの Durable Object。接続の管理、定規の所持確認、対戦結果の記録 |
| `public/shared/core.js` | 部屋の進行（入退室・モード・開始・はじく・判定・再接続）。Cloudflare に依存しないので、コンピュータとの練習ではブラウザの中でも動かす |
| `src/auth.js` | Googleログインとセッション |
| `src/api.js` | アカウントのAPI（プロフィール・装備・ガチャ・戦績） |
| `src/db.js` | データベースの操作（テーブルの自動作成、ガチャ、報酬、戦績） |
| `public/shared/physics.js` | 物理計算（摩擦・衝突・はじく力・アクセサリの効果） |
| `public/shared/rules.js` | 机の大きさ、モード、席の配置、色 |
| `public/shared/catalog.js` | アイテムの一覧、レア度と確率、えんぴつの数値 |
| `public/app.js` | 画面の切り替え、通信、はじく操作、動きの再生 |
| `public/practice.js` / `public/shared/cpu.js` | コンピュータとの練習（ブラウザの中で部屋を動かす）と、コンピュータの打ち方 |
| `public/account.js` | ログイン表示とマイページ（定規ケース・ガチャ・戦績） |
| `public/admin.html` / `public/admin.js` | 設定画面（管理者だけ） |
| `public/board.js` / `public/ruler-paint.js` | 盤面と定規（形・素材・柄・シール・オーラ）の描画 |
| `public/ruler-info.js` | 定規のレベル・属性の表示 |
| `test/` | テスト |

## 調整したい値

- えんぴつの数、ガチャの確率、アクセサリの効き目：設定画面から（初期値は `public/shared/catalog.js`）
- 定規の形・素材（重さ・すべりやすさ・跳ね返り）・三すくみの強さ：`public/shared/physics.js` の `SHAPE_DEFS`・`MATERIALS`・`AFFINITY_BONUS`
- レベルの上限・上がり方：`public/shared/catalog.js` の `LEVEL_MAX`・`LEVEL_STEP`・`expToNext`
- 机の大きさとモード、机が消え始める人数、クリティカルの確率と強さ、必殺技の割り当て・強さ・ゲージのたまり方：`public/shared/rules.js`（`SHRINK_FROM_PLAYERS`・`CRIT`・`SHAPE_SKILL`・`SKILL_TUNE`・`GAUGE`）

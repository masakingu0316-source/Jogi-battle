# 定規バトル（オンライン版）

机の上で定規をはじき合う遊びを、離れた端末どうしで対戦できるようにしたWebアプリです。
部屋を作ると5文字の部屋コードと招待リンクが出て、友だちはそれを開くだけで入れます。
Googleでログインして遊びます。戦績や集めた定規・アイテムはアカウントに保存されます。

## できること

**遊ぶ流れ**
1. Googleでログインする（招待リンクから来た人は、ログイン後にそのまま部屋へ）
2. ホーム（スクロールなしの1画面）で、中央の「対戦」からモードを選んで部屋を作る（コンピュータとの練習もここ）／「部屋に入る」で友だちの部屋コードを入れる／「ステージ」で1人で攻略する
3. 部屋で全員が「準備OK」を押すと対戦が始まる。人数がそろってから（最後の人が入ってから）1分たつと、準備中の人も一緒に始まる
4. 決着したら同じ部屋に戻り、また全員の準備OK（または1分）で次の対戦。抜けたい人は「部屋を出てホームへ」

**対戦**
- 見た目：和モダン（白練の紙に青海波、墨・藍・朱の配色、夜は藍色に金の差し色）。見出しは筆文字（Yuji Syuku）、カットインと盤面の大きな文字は行書ふうの筆文字（Yuji Mai）、本文は BIZ UDPゴシック。どれも Google Fonts から読み込み、読み込めない端末では明朝体などで表示する
- 対戦中の画面：上にほかの人を縦に並べ（番の人の体力と必殺技のゲージを大きく）、下に自分の体力を大きく、左下に必殺技の円ゲージを出す。円ゲージが満タンのとき、自分の番に押すと必殺技を構える
- モード：クイック（1対1・机1台）／標準（1対1・机2台）／乱戦（3〜4人・机4台）／チーム戦（2対2・机4台）。部屋を作るときに決め、定員を超えては入れない
- 最初の1周は、落ちても元の席に戻る
- 机が消える：3人以上で始めた対戦で残りが2人になると、机が1台ずつ消える（最後は1台まで）。消える机は赤い斜線で予告し、予告が出てから2人とも必ず1回ずつ番を終えたら（連打は2打目まで終えたら、時間切れで飛ばされた番も1回）消える。まだ番が残っている人は画面上の札に出る。消えたときに上にいた定規は落ちる（だれの手柄にもならない）。どの机が消えるかはランダムだが、残りの机が角だけでつながる形にはしない
- 体力：定規はそれぞれ体力100で始まる。当てられた側だけが、ぶつかった勢いに応じてダメージを受ける（強く当てても1回35まで。クリティカルは1.5倍、突風は近いほど最大18）。体力が0になっても、落ちるまでは負けない
  - 押されたときの飛びやすさが体力で変わる：満タンで今までの0.6倍しか飛ばず、0で1.6倍飛ぶ（はじいた本人のすべり方は変わらない）
  - 盤面の定規のすぐそばに、席の色の印つきで体力の小さな札（バーと数字）が出る。ほかの札や定規と重なりにくい場所に自動で置き、狙っている自分の定規の札は薄くなる。体力30以下は赤く点滅
  - 体力が減った定規にはヒビが入り、ぶつかった瞬間に「-12」のような数字が出る
  - 1周目に落ちて席に戻っても、受けたダメージは残る
- 必殺技：はじく（+20）・相手に当てる（1本につき+10）・当てられる（+30）でゲージがたまり、満タンなら自分の番に左下の円ゲージを押して使う。技は銘柄ごとに決まり（設定画面で変えられる）、全部で20種類（うち5種類はSSR専用）
  - 構えてからはじく技（その1打に効く）：剛腕（力が大きく上がる）・連打（もう1回はじける）・突風（周りを吹き飛ばす）・不動（次の自分の番まで重くなる）・渾身（当てた相手へのダメージ2.5倍）・インク漏れ（当てた相手は3周のあいだ毎番5ダメージ）・爆発（止まった場所で爆発、近くに大ダメージ）・磁石（周りの定規を引き寄せる）
  - その場で使う技（押すと説明、もう一度押すと発動。そのあとふつうにはじける）：保健室（体力35回復）・身代わり（1回だけ、落ちても真ん中に戻る。体力は半分）・反撃（次の自分の番まで、受けたダメージを当てた相手にも返す）・ワープ（机の真ん中の空いた所へ移る）・いす召喚（近い辺に椅子、1周落ちない）・吹雪（次の人の番、机が凍る）
  - 使うと、全員の画面に必殺技のカットイン（墨の一筆の帯が横切り、使った人の定規と、技の名前を筆文字で出す）が約1秒出る。構えてはじく技は、カットインのあとで動き出す
  - 初期の割り当て：30cm（アクリル 剛腕／メタル 不動／ラバー 突風）、15cm（連打／保健室／ワープ）、三角45°（渾身／反撃／インク漏れ）、三角30°60°（突風／いす召喚／吹雪）、分度器（爆発／身代わり／磁石）
- クリティカルヒット：はじくたびに10%の確率で発生し、最初に当てた相手へ伝わる力が1.6倍になる（すべる距離はおよそ2.5倍）。相手に当たらなければ何も起きない
- 再戦は先手が交代する。対戦中に抜けた人の席は、決着したときに空く
- 通信が切れても、開き直せば同じ席に戻れる。切れた人の番は、いちばん先に部屋にいた人が飛ばせる

**コンピュータと練習**
- ホームの「コンピュータと練習」から、上で選んだ遊び方でコンピュータと対戦できる。強さは「やさしい／ふつう／つよい」、乱戦はコンピュータの人数（2人か3人）も選べる。チーム戦は味方1人・相手2人
- コンピュータは、実際にいくつものはじき方を計算してみて良いものを選ぶ。強いほど試す数が多く、手元のぶれが小さい（定規もやさしいLv.1・ふつうLv.3・つよいLv.6）
- 練習はブラウザの中だけで動き、サーバーとは通信しない。えんぴつ・経験値・戦績は増えない

**ステージ（1人で攻略）**
- ホームの「ステージに挑む」から。文房具の敵を、体力0にするか机から落として倒しながら進む。番は「自分 → 敵が1体ずつ」の順
- ステージ1「可変定規編」：マップ10個。マップ1から順に、クリアすると次が開放される。1マップは盤面3つ（マップ10は5つ）で、盤面の敵を全部倒すと次の盤面へ
- ライフは1マップに3つ。机から落ちても2回までは、その盤面の最初の位置（ふさがっていれば空いている所）に戻れる（体力が最大の半分より少なければ半分まで戻る）。3回目に落ちたらそのマップは失敗（最初の盤面からやり直し）。体力0では負けない。体力と必殺ゲージは次の盤面へ持ち越し、盤面クリアごとに体力+20
- 敵（マップが進むほど体力・当たり・はじく力が上がり、はじき方もうまくなる）
  - 動く：鉛筆（軽くよくすべる）・クリップ（小さく重め）・ホチキス（重く強い）・敵の定規（形と素材ごとの必殺技も使う）
  - 置物：消しゴム（とても滑りにくく体力が少ない。そばにいると削ってくる）・画びょう（刺さって動かない。ぶつかるとトゲでダメージ）・スティックのり（周りの机がねばって止まりやすい）・修正テープ（近くの敵を直す）・コンパス（刺さって動かない。近づいた定規を弾き飛ばす）
  - ラスボス：折りたたみ定規。体力が減るほど「たたんだ形 → 半分 → 全開（約52cm）」と長くなり、必殺技「全開」も使う
- 机：1台・2台・4台のほか、横一列3台・L字・6台・ロの字（真ん中が穴）
- 報酬：クリアのたびに使った定規へ経験値（マップ1で28点〜マップ10で150点）。初クリアでえんぴつ（10〜150本）。マップ10の初クリアで「折りたたみ定規（アクリル）」
- レベル：ステージでは Lv.50 まで効く（対人の対戦では今までどおり Lv.10 まで。経験値は共通で、対人で Lv.10 を超えた分もたまっていく）。ステージでは、レベル1つごとに体力の最大も3増える（Lv.50で247）
- 折りたたみ定規（アクリル）は対人の対戦でも使える。体力が減るほど伸び、必殺技「全開」でその1打だけいちばん長い形になって、当てた相手へのダメージが1.8倍
- 計算はすべてサーバー（1人に1つの Durable Object）で行い、クリアの記録と報酬もサーバーが付ける。途中で画面を閉じても、1日以内ならステージ選択の「続きから」で再開できる

**ホーム画面**
- 上から「資源の帯（えんぴつ・名前・毎日ボーナスまでの残り時間）／相棒の定規／大ボタン3つ（ステージ・対戦・部屋に入る）」、下にタブ（ホーム・定規ケース・ガチャ・戦績・その他）。縦持ちのスマホ（幅360〜430px）でスクロールせずに収まり、PCでは中央に縦長で出す（左右は題字と目盛りの飾り）
- 相棒の定規：机の上に少し斜めに大きく置き、レア度の札・名前・Lv・重さ（藍）とはじく力（朱）のバー・必殺技・特性（SR以上）を出す。左右の矢印かスワイプで、持っている定規に持ち替えられる（対戦で使う定規も変わる）。押すと定規ケースの編集が開く
- 受け取り箱（右上の箱、受け取っていない数を朱の丸で表示）：毎日ボーナス・ステージの初クリア報酬（えんぴつと折りたたみ定規）・定規ガチャの天井のSSR交換券・管理者からの配布が届き、押して受け取る（期限なし）。持っている定規が届いたら、えんぴつに変わる
- 定規ケースのタブには、新しく手に入れた定規があると朱で「NEW」が出る

**定規の銘柄・レア度・特性**
- 定規は1本ずつ名前と絵柄を持つ「銘柄」。レア度は N（学習定規）・R（教室の持ち物）・SR（製図用）・SSR（漆・蒔絵・金箔の工芸品）
- レア度で重さ・はじく力が上がる（N±0・R+2%・SR+4%・SSR+6%）。レベルとアクセサリの効果とは掛け算で重なり、合わせて最大+16%
- 特性（SR以上がいつも持つ。ゲージは使わない）：目盛り読み（狙う矢印が2割長く見える）・鋭い縁（当てたときのダメージ+5%）・ふんばり（すべりにくさ+8%）・方眼（はじいたときのゲージ+5%）・重心（当てられたときの飛び方−3%）
- SSR専用の必殺技（全20種類）：一文字（回らずにまっすぐすべり、最初に当てた相手には必ずクリティカル）・ゴム跳び（机の端で1回跳ね返る）・虹の道（照準線に跳ね返りの先まで見え、はじく力1.3倍）・一角（いちばん鋭い角の先で当てると弾く力2倍・ダメージ1.5倍）・百八十度（曲がる角度を決めてはじくと、150ミリ秒後に1回曲がる）
- 第1弾：N15本（今までの形×素材）・R6本・SR5本・SSR5本と、ステージ報酬の折りたたみ定規（SSR）。30cm定規（3つの素材）は全員が最初から持っている
- 部屋を作るときに「公平」を選ぶと、レア度・レベル・アクセサリの上乗せがなくなる（特性と必殺技は残る）

**アカウント**
- 戦績：対戦数・勝ち・勝率・落とした数・自滅、モード別の成績、最近20戦の履歴
- 定規の形：30cm定規・15cm定規・三角定規（45°）・三角定規（30°・60°）・分度器（と、ステージ報酬の折りたたみ定規）
- 定規の属性（素材）：アクリル（よくすべり、よく跳ね返る）／メタル（重くて押されにくい）／ラバー（すぐ止まり、跳ね返らない）。三すくみで、メタル→アクリル→ラバー→メタルの順に、当てたとき相手を少し強く弾ける
- 定規のレベル：対戦で使った定規に経験値が入る（参加10点、勝ち+10点、1本落とすごとに+5点）。対人ではLv.10まで（ステージではLv.50まで）。1つ上がるごとに重さとはじく力が0.4%上がり（Lv.10で+3.6%）、Lv.3からオーラ、Lv.6から光の粒、Lv.10で金色の輪をまとう
- 定規ケース：ゲームの BOX のように、全部の定規を正方形のアイコンで並べる（枠の色＝レア度、左下＝レベル、暗いマス＝まだ持っていない定規）。コレクションの数、並び順（取得順・レベル順・レア度順・形順）、素材でのしぼり込み、手に入れて3日以内の定規には NEW。アイコンを押すと、柄・シール（見た目）とアクセサリ（性能）を付けて「使う定規」にできる。まだ持っていない定規は手に入れ方が出る
- アクセサリ：重さ・すべりにくさ・はじく力のどれかを最大5%変える。1本の定規に1つまで（レベルの分と合わせて最大10%）
- ガチャ（通貨は「えんぴつ」。確率は画面に表示。お金で買う仕組みはありません）
  - 定規ガチャ：定規だけが出る。1回30本・10回300本（10回はSR以上が1本確定）。確率 N55・R30・SR12・SSR3。持っている定規が出たら、えんぴつに変えて返す（N2・R5・SR15・SSR50）。100回引くと受け取り箱に「SSR交換券」が届き、好きなSSRを1本選べる
  - 飾りガチャ：柄・シール・アクセサリ（今までのガチャ）
- えんぴつのもらい方：はじめてのログイン、毎日ボーナス（受け取り箱）、対戦の参加と勝ち、ステージの初クリア（受け取り箱）。本数は設定画面で変えられる

## しくみ

```
ブラウザ（public/）  ──WebSocket──  Cloudflare Worker（src/worker.js）
                                      ├ 部屋ごとの Durable Object（src/room.js）
                                      │   └ 部屋の進行と物理計算（public/shared/core.js）
                                      ├ ステージ：1人に1つの Durable Object（同じ Room クラス、src/stage-host.js）
                                      │   └ ステージの進行と敵の打ち方（public/shared/stage-core.js）
                                      ├ Googleログイン（src/auth.js）
                                      └ アカウントのAPI（src/api.js）── D1 データベース（src/db.js）
```

- **サーバーが判定する**：はじいた向き・強さだけをサーバーに送り、サーバーが物理計算をして、定規の動きを全員に配ります。持っていない定規やアクセサリは、サーバーが確認して使えないようにしています。
- **ログイン**：Googleの認可コード方式（PKCE付き）。端末には推測できないセッションIDだけをクッキーで持たせ、データベースにはそのハッシュを保存します。保存するのはGoogleのアカウント識別子と表示名だけで、メールアドレスは受け取りません。
- **データベース**：テーブルは最初に使ったときに自動で作られます。
- **部屋の片付け**：6時間だれも使わなかった部屋は自動で削除されます。
- **版の確認**：`public/shared/version.js` の値をサーバーと画面で比べ、画面を開いたままの端末が古い版のときは「再読み込み」を出します（対戦中でも同じ席に戻れます）。更新を公開するときは、この値を変えてください。

## 公開のしかた（GitHub → Cloudflare）

必要なもの：GitHub のアカウント、Cloudflare のアカウント（無料プランで動きます）。
Cloudflare や Google の画面の表記は変わることがあるので、近い名前のボタンを探してください。

1. **GitHub にリポジトリを作り**、このフォルダの中身を入れる（`node_modules` は不要）
2. **Cloudflare の「Workers & Pages」→「作成」→ GitHub のリポジトリを読み込む**で、1 のリポジトリを選ぶ
3. デプロイコマンドは `npx wrangler deploy`（初期値のまま）、ビルドコマンドは空欄でよい
4. 以降は GitHub の main ブランチに変更を入れるたびに、自動で公開し直される

この時点ではログインが使えないので、ログイン画面に「準備ができていません」と表示されます。続けて「ログイン機能を有効にする」を済ませてください。

## ログイン機能を有効にする

### A. データベースを作る（Cloudflare）

1. ダッシュボードの「ストレージとデータベース」→「D1 SQL データベース」→「作成」
2. 名前を `jogi-battle-db` にして作成し、表示される **データベースID** を控える
3. `wrangler.jsonc` の `"d1_databases"` の行の先頭の `//` を外し、`ここにデータベースのID` を書き換える

### B. Googleログインの準備（Google Cloud）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る（名前は自由）
2. 「Google Auth Platform」（または「APIとサービス」→「OAuth同意画面」）を開き、アプリ名（例：定規バトル）とサポート用のメールを入れる。対象は「外部」
3. 「クライアント」→「クライアントを作成」→ 種類は「ウェブ アプリケーション」
4. 「承認済みのリダイレクト URI」に次を追加する（自分のURLに合わせる）
   `https://jogi-battle.<あなたのサブドメイン>.workers.dev/auth/callback`
5. 作成後に出る **クライアントID** と **クライアントシークレット** を控える
6. 「対象」（Audience）で公開ステータスを「本番環境」にする。テスト中のままだと、テストユーザーに登録した人しかログインできない
   （このアプリが求めるのは名前などの基本情報だけなので、Googleの審査は通常いりません）

### C. 値を設定する

1. Cloudflare のダッシュボードで、この Worker の「設定」→「変数とシークレット」→「追加」から、種類「シークレット」で次の2つを登録する
   - 名前 `GOOGLE_CLIENT_ID`、値にクライアントID
   - 名前 `GOOGLE_CLIENT_SECRET`、値にクライアントシークレット
2. `wrangler.jsonc` の変更（データベースID）を GitHub に入れる（自動で公開し直される）

クライアントIDもシークレットも、GitHub のファイルには書かないでください（GitHub の検査で警告が出ます）。

画面右上に「Googleでログイン」が出れば完了です。

## 設定画面（管理者だけ）

`https://jogi-battle.<あなたのサブドメイン>.workers.dev/admin.html` で、コードを触らずに次のことができます。

- えんぴつ：ガチャの値段、はじめてのログイン・毎日のログイン・対戦でもらえる本数、対戦の1日の上限
- 定規の経験値：対戦に使った・勝った・1本落としたときの点数
- 定規ガチャ：値段、レア度ごとの確率（重み）、持っている定規が出たときに返す本数、天井の回数
- 定規の銘柄：銘柄ごとの名前・レア度・絵柄・特性・必殺技・ガチャに出すか。新しい銘柄の追加（形と素材を選ぶ）。銘柄は消せないので、使わなくなったらガチャから外す
- レア度の上乗せ・特性の効き目・SSRの技の数値
- 飾りガチャ：レア度ごとの確率（重み）と、かぶったときに戻る本数。アイテムをガチャに出すかどうか、アクセサリの効き目（−5〜5%）
- 定規の性能（形・素材ごと）：重さ・すべりにくさ・跳ね返り・はじく力（50〜150%）。同じ形・素材の銘柄すべてに効く
- ユーザー：表示名やアカウントIDで探して、えんぴつを配る（受け取り箱に届く。見出しも付けられる）・減らす（すぐ）

保存した値はデータベースに入り、30秒ほどで全体に反映されます。「初期値に戻す」で、コードに書いた値（`public/shared/catalog.js`）に戻ります。

**管理者の登録**
1. 自分のアカウントでログインし、下のタブの「その他」にある **アカウントID** を控える（設定画面を開いたときにも表示されます）
2. Cloudflare でこの Worker の「設定」→「変数とシークレット」→「追加」から、種類「シークレット」、名前 `ADMIN_USER_IDS`、値にアカウントIDを登録する（複数人ならカンマ区切り）
3. 1〜2分後に設定画面を開き直す

## 調整したい値

- 定規の銘柄・レア度の上乗せ・定規ガチャ：設定画面から（初期値は `public/shared/catalog.js` の銘柄の一覧・`RARITY_BONUS`・`RULER_GACHA`）
- 特性とSSRの技の数値：設定画面から（初期値は `public/shared/rules.js` の `TRAITS`・`SKILL_TUNE`）

- えんぴつの数、ガチャの確率、アクセサリの効き目：設定画面から（初期値は `public/shared/catalog.js`）
- 定規の形・素材（重さ・すべりやすさ・跳ね返り）・三すくみの強さ、体力（飛びやすさの幅・ダメージの大きさ）：`public/shared/physics.js` の `SHAPE_DEFS`・`MATERIALS`・`AFFINITY_BONUS`・`HP`
- レベルの上限・上がり方：`public/shared/catalog.js` の `LEVEL_MAX`・`STAGE_LEVEL_MAX`・`LEVEL_STEP`・`expToNext`
- ステージの敵・マップ・報酬・難しさ：`public/shared/stage.js`（`ENEMIES`・`STAGES`・`SCALE`・`aiOf`・`STAGE_HP`・`BOARD_HEAL`・`REWARD`）。敵の重さ・すべりやすさは `physics.js` の `ENEMY_SPECS`
- 机の大きさとモード、机が消え始める人数、クリティカルの確率と強さ、必殺技の種類・初期の割り当て・強さ・ゲージのたまり方、場のイベントの確率・こおりのすべり方：`public/shared/rules.js`（`SHRINK_FROM_PLAYERS`・`CRIT`・`SKILLS`・`RULER_SKILL`・`SKILL_TUNE`・`GAUGE`・`EVENTS`）
